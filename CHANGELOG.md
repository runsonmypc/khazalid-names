- Extract the sourced Khazalid naming system as an independent vanilla-plus-DFHack mod.
- Add separate mod, command, script, translation and hook identities, with new-world installation and naming-provider conflict refusal.
- Preserve reviewed personal/place catalogs, supported new-institution and squad naming routes, explicit previews and all compatible item-aware artifact alternatives.

Public release, licensing review and standalone native compatibility qualification remain gates; this entry does not assert that they have passed.

Standalone verification: DF 53.14 / DFHack 53.14-r2 in a fresh vanilla-content Windows/Wine lab; world generation, native institution creation, artifact fixture/GUI regressions and cold-reload name preservation passed. No original fork runtime files were changed.
