Appearance families group spellings after removing only black, red, yellow, bright blue and shining. This is an editorial measure of variety, not grammatical equivalence. The interface spreads these variants apart. The twelve non-artifact categories in the second table contain 867 category entries but 518 distinct spellings across categories; do not sum them as unique worldwide identities.

Artifact titles contain 475 pairs and 527 explicitly grouped triples from 49 attested roots. The full 1,002 is a browsing catalog; each real item can use only compatible titles. Illustrative capacities before occupied-name filtering:

Profiles describe the matcher, not a promise that vanilla DF contains every listed weapon type. A highly specific item may have one strongest fit; other compatible tiers remain selectable. Native independent draws can repeat, and family inheritance deliberately repeats surnames. Explicit edits reject occupied names in their relevant scope. Creation can reuse reviewed institution names when its finite pool is exhausted; it does not invent unsupported replacements.
